# Zeus Changelog

## 0.1.0 — Identity foundation

- Established **Zeus** as the Next Labs product identity.
- Migrated the Python package namespace to `zeus`.
- Migrated configuration variables to the `ZEUS_*` namespace.
- Migrated project-owned model IDs to `zeus-latest` and `zeus-0.1`.
- Migrated Docker service/image identity and runtime examples to Zeus.
- Reworked primary documentation, packaging and tests around the Zeus identity.
- Preserved the imported decision algorithms and HTTP endpoint shapes.
- Preserved Apache-2.0 licensing and immutable historical provenance.
