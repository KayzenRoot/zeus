# Zeus Definition of Done

A Zeus increment is complete only when:
- admitted Work Order scope is implemented and nothing material outside scope is introduced;
- acceptance criteria pass;
- unit/integration/build/lint/type/security checks appropriate to risk pass;
- exact-head Evidence Bundle exists;
- no unresolved HIGH/CRITICAL finding remains;
- audit verdict is APPROVED;
- affected canonical sources and checkpoint are updated after approval;
- PR is merged without destructive history rewriting.

- no active upstream-brand reference remains outside approved historical/legal provenance;
- Python package/import namespace is Zeus;
- environment namespace is Zeus;
- Docker and documentation identity are Zeus;
- behavior remains equivalent to the pre-rebrand baseline;
- tests pass.
