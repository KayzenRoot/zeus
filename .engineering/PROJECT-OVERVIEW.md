# Zeus Project Overview

Zeus is a Next Labs AI decision-engine project derived from a pinned Apache-2.0 upstream baseline. The current phase establishes Zeus identity without changing functional behavior.

Current goal: preserve the verified decision-server behavior while replacing product identity, package/module naming, environment-variable namespace, Docker/service naming, documentation and tests from the upstream brand to Zeus.

Repository visibility remains PUBLIC temporarily for CI. No secrets, private credentials or confidential provider configuration may be committed.

Future capabilities are not admitted by this document; they require separate Work Orders.
